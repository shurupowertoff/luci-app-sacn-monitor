# Changelog

## 0.2.1

- Прокручиваемая сетка из 512 DMX-каналов с адресами, значениями и индикаторами уровня.

## 0.2.0

- График суммарного PPS за последние две минуты в открытом LuCI.
- Просмотр до 512 DMX-каналов по Universe и источнику.

## 0.1.0

- Демон пассивного захвата sACN и ограниченная таблица потоков по CID и Universe.
- Статистика частоты, приоритета, активности, пакетов и нарушений последовательности через ubus.
- Панель LuCI с сортировкой, настройкой устройства захвата и управлением сервисом через procd.
- Пакет APK для OpenWrt 25.12.6, workflow GitHub Actions и локальные тесты E1.31.
