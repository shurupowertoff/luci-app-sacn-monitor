# SACNMON

Пассивный монитор потоков sACN (ANSI E1.31) в **Status → SACNMON**. Целевая платформа — OpenWrt 25.12.6, Cudy WR1300 v3, `ramips/mt7621`, `mipsel_24kc`, APK. Демон на C использует libpcap 1.10.6 и ubus. LuCI обновляет статистику каждые две секунды.

График показывает суммарный PPS за последние две минуты с момента открытия страницы. В разделе **DMX channel values** выберите Universe, источник и диапазон из 64 каналов. Значения показываются в десятичном виде от 0 до 255. Прочерк означает, что канал отсутствовал в последнем пакете. Если поток перестаёт быть активным, таблица показывает последние полученные значения с отметкой о состоянии. Источники одного Universe можно просматривать отдельно.

## Сборка

GitHub Actions запускает тесты и собирает APK с официальным SDK OpenWrt. ZIP с APK и его SHA-256 публикуется в артефактах запуска. Для локальной сборки на x86_64 Linux нужны Docker, доступ к GHCR и источникам пакетов OpenWrt, а также свободное место для SDK и промежуточных файлов.

```sh
./scripts/test.sh
./scripts/build-apk.sh
```

Скрипт запускает [официальный контейнер SDK](https://github.com/openwrt/docker-openwrt/pkgs/container/sdk) версии 25.12.6 для ramips/mt7621, фиксирует SHA-256 образа, использует feeds из SDK и кладёт APK и SHA-256 в `artifacts/`. Можно задать выходной каталог первым аргументом и число параллельных задач в `JOBS`.

Имена зависимостей в OpenWrt SDK — `libpcap`, `libubox`, `libubus`, `luci-base` и `rpcd`. SDK разрешает ABI-суффиксы библиотек при упаковке. Сборка использует [исходники OpenWrt 25.12.6](https://github.com/openwrt/openwrt/tree/v25.12.6) через официальный SDK.

## Установка и удаление

Проверьте версию и архитектуру на роутере, затем обновите индекс стандартных репозиториев OpenWrt.

```sh
ubus call system board
apk --print-arch
apk update
```

Проверьте SHA-256 артефакта перед копированием APK в `/tmp` на роутере. Для доверенного локального APK из CI без ключа в хранилище роутера используйте `--allow-untrusted` только для этой установки.

```sh
apk add --allow-untrusted /tmp/luci-app-sacn-monitor-0.2.0-r1.apk
```

При обновлении работающего SACNMON перезапустите службу командой `/etc/init.d/sacnmon restart` и обновите страницу LuCI.

На странице **Status → SACNMON** выберите Linux-устройство захвата, например `br-lan`, и нажмите **Save & Apply**. На этой же странице доступны запуск, остановка и управление автозапуском. Стандартные скрипты OpenWrt запускают и включают новый сервис при установке. Чтобы остановить и удалить пакет:

```sh
/etc/init.d/sacnmon stop
/etc/init.d/sacnmon disable
apk del luci-app-sacn-monitor
```

## Диагностика

```sh
uci show sacnmon
/etc/init.d/sacnmon status
/etc/init.d/sacnmon enabled
ubus call sacnmon.control status
ubus -v list sacnmon
ubus call sacnmon stats
logread -e sacnmond
```

Если демон не запущен, объект `sacnmon` отсутствует. При смене интерфейса работающий демон перезапускается, и накопленные счётчики сбрасываются. При запущенном демоне `capturing` показывает состояние захвата, `capture_drops` — потери захвата по данным libpcap, `untracked_packets` — пакеты новых потоков при заполненной таблице. На тестовом стенде наличие пакетов можно проверить отдельно, если установлен `tcpdump`. Флаг `-p` оставляет promiscuous mode выключенным.

```sh
tcpdump -p -ni br-lan -c 20 'udp dst port 5568'
```

Поток определяется парой **CID + Universe**. Адрес, имя и Priority берутся из последнего принятого пакета. Поток становится неактивным через 2,5 секунды без пакетов или сразу при `Stream_Terminated`. Время последнего пакета в LuCI вычисляется по возрасту из монотонных часов демона и локальному времени браузера. PPS измеряется за последнюю завершённую секунду. Счётчик нарушений увеличивается для повторов, перестановок и скачков Sequence Number, переход 255 → 0 считается штатным. По этому счётчику нельзя вычислить число потерянных в сети пакетов.

## Ограничения захвата

- Захватываются видимые Linux кадры Ethernet с IPv4 UDP на порт 5568, включая до двух заголовков 802.1Q/802.1ad. Статистика учитывает E1.31 Data Packets с DMX Start Code 0x00. Альтернативные Start Code (в том числе Per-Address Priority), IPv6, IP-фрагменты и служебные пакеты синхронизации и обнаружения Universe не учитываются. grandMA2 учитывается как источник при отправке sACN. MA-Net может работать в той же сети, его пакеты не декодируются.
- Приложение не отправляет sACN, не включает promiscuous mode, не подписывается на multicast и не меняет firewall, маршрутизацию, интерфейсы либо аппаратное ускорение. Изолированная сеть `2.0.0.0/8` настраивается отдельно. Аппаратный switch/offload, multicast snooping и unicast между другими портами могут скрыть трафик от CPU роутера. Для проверки наблюдаемости используйте тестовый источник, внешний TAP или заранее настроенное внешнее зеркалирование.
- До 256 потоков, буфер захвата 256 КиБ и до 128 пакетов за цикл в 20 мс. При заполнении таблицы старые неактивные записи освобождают место новым потокам. При перегрузке возможны пропуски мониторинга. Размер буфера ядро может округлить. Статистика хранится в RAM и пропадает при перезапуске.
